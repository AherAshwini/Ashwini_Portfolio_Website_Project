# Ashwini Aher — Portfolio

React 18 + Vite 5 single-page portfolio site.

## Run locally

```bash
npm install
npm run dev       # http://localhost:5173
```

## Other commands

```bash
npm run lint      # ESLint (eslint:recommended + react + react-hooks)
npm run build     # production build → dist/
npm run preview   # preview the production build locally
```

## Notes

- All content in `src/data/*.js` is sourced directly from the résumé
  (`public/Ashwini_Aher_Resume.pdf`) and the two conference certificates
  (`public/certificates/`). See the code comments in those files for
  verification notes and open items.
- Not deployed anywhere — this is the source only.
